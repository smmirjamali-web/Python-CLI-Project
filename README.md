📦 Python CLI Projects


A collection of small command-line applications built while learning Python.
Each project focuses on strengthening fundamentals such as variables, loops, functions, data structures, and CLI interaction.


📁 Projects


🔐 Password Generator

Generates secure random passwords using Python with customizable length and 
character sets.

🎯 Number Guessing Game

A simple game where the user tries to guess a randomly generated number.

📝 Todo CLI

A minimal, interactive command-line todo list manager with add, list, and delete features.

📒 Contact Book CLI (New)

A simple contact management program that allows users to add, view, search, and delete contacts.
Includes input validation and clean formatted output.
