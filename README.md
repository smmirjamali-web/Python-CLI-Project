# Python CLI Projects

A collection of small command-line applications built while learning Python.

## Projects

### Password Generator
Generates secure random passwords using Python.

### Number Guessing Game
A simple command-line game where the user guesses a random number.

### Todo CLI
A minimal command-line todo list manager.

## Purpose

These projects are built for learning Python fundamentals and practicing problem solving using command-line interfaces.

- Python
- CLI (Command Line Interface)
