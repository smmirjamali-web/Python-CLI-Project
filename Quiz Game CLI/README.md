Quiz Game CLI

A simple command-line quiz game written in Python.

The game loads questions from a JSON file and lets the player answer multiple-choice questions.

This is a small practice project while learning Python, focusing on working with JSON files, loops, error handling, and building simple CLI applications.
Features

    Loads quiz questions from a questions.json file
    Multiple-choice questions
    Score calculation at the end of the quiz
    Basic input validation
    Simple and clear CLI interface

How to Run

    Make sure you have Python 3 installed.
    Clone this repository or download the files.
    Run the program:

python main.py

The quiz will start in the terminal.
