To‑Do CLI (Python)

A simple command‑line To‑Do application written in Python.

This project was created as beginner practice to work with basic Python concepts.
Features

    Add a new task
    Show all tasks
    Remove a task by its number

Concepts Practiced

    Lists
    while loops
    if / elif conditions
    user input
    enumerate()
    basic CLI interaction

Run:

python main.py

This project is only for learning and practicing basic Python programming.
