# Expense Tracker CLI (Python)

A simple **Command Line Expense Tracker** written in Python.  
This project is part of my learning journey as I practice Python by building small CLI applications.

The program allows users to record expenses, view them, search by category, and calculate total spending.  
Expenses are saved in a **JSON file**, so the data remains available the next time the program runs.

---

## Features

- Add a new expense  
- View all expenses  
- Search expenses by category  
- Calculate total expenses  
- Save and load data using JSON  
- Simple command-line interface

---

## How It Works

Each expense contains:

- Title  
- Amount  
- Category  

Example:

Title: Coffee

Amount: 3.5

Category: Food


All expenses are stored in a file named:

expenses.json
