# Number Guessing Game 🎯

A simple beginner-friendly Python CLI game created for learning and practice.

The player tries to guess a randomly generated number between 1 and 100.

## How It Works

- The program generates a random number between 1 and 100.
- The player enters guesses.
- The program tells the player if the guess is too high or too low.
- The game continues until the correct number is guessed.

## Features

- Basic input validation (only numbers allowed)
- Range validation (1 to 100)
- Unlimited attempts

## Purpose

This project is part of my beginner Python practice and is intended to help reinforce basic programming concepts such as:
- loops
- conditionals
- user input
- working with the `random` module
